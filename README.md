# AI Reception

AI Reception is a product of LABRITY.

## Concept

An AI-powered online booking and digital receptionist platform for small and medium-sized businesses. The product gives a business a digital AI receptionist that can later be integrated into the company's website: it chats with customers, helps them choose a service and a suitable free time slot, and creates, changes or cancels appointments in the company's calendar. In the future the product is intended to be adaptable to other types of businesses.

## Initial target market

German Kfz-Werkstätten (car repair shops)

## Status

Early development — ServiceOS codebase (Next.js). See [HANDOFF_GRAPH.md](./HANDOFF_GRAPH.md) for architecture, current state, and what to resume next.

## Development

This is a [Next.js](https://nextjs.org) project.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Other scripts: `npm run typecheck`, `npm run test`, `npm run build`.
