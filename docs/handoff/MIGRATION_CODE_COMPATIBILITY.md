## Зависимости порядка миграций
- 0033 заменяет тела функций из 0029/0031/0032 и вешает триггеры на `clients.archived_at` → **требует 0029–0032 уже применёнными.** Без них миграция падает.
- Нельзя повторно применять 0029/0031/0032 после 0033 (вернутся старые функции с прямой вставкой в аудит → отказ). В тестах это учтено (после повтора применяется 0033).
- 0028–0032 между собой можно применять по номерам одним проходом, но каждая — после резервной копии и восстановления в тестовую базу.
